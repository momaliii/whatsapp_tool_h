FAQ

Good to know

Do I need the WhatsApp Cloud/Business API?

No. watitool uses your normal WhatsApp by scanning a QR code (WhatsApp Web), so there are no API approval steps or per-conversation Meta fees.

Is it safe for my number?

It's built to be careful — random delays, typing indicators, batch breaks and a registered-number check. No tool can guarantee against bans, so we recommend warming up new numbers and only messaging people who expect to hear from you.

How is the per-message price calculated?

Pay-as-you-go averages 2.5–3 EGP per message. Larger volumes trend toward the lower end. Use the calculator above to estimate any volume.

Can it reply automatically?

Yes — set keyword auto-replies or build interactive menu flows that wait for the user's reply, branch, and collect information.
